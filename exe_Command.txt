# Tercih edilen yol: spec dosyasi (ayarlar orada, tek kaynak)
#
#   pyinstaller --noconfirm NvidiaConvertor.spec
#
# NvidiaConvertor.spec icindeki ONEDIR degiskeni:
#   True  -> klasor cikti  (TASINABILIR dagitim icin onerilen)
#   False -> tek dosya exe (her acilista icerigi temp'e acar)
#
# FFmpeg'i pakete dahil etmek icin: proje klasorunde "ffmpeg" adinda bir
# klasor olusturup icine ffmpeg.exe ve ffprobe.exe koyun. Spec bunlari
# otomatik paketler; uygulama calisirken kendi yanindakini kullanir.
#
# ------------------------------------------------------------
# Spec kullanmadan, dogrudan CLI ile (DIKKAT: .spec dosyasinin
# uzerine yazar ve oradaki ayarlar kaybolur):
#
# Klasor cikti (tasinabilir):
#   pyinstaller --noconfirm --onedir --windowed --name NvidiaConvertor --icon "icon.ico" --add-data "icon.ico;." --collect-all customtkinter --collect-all tkinterdnd2 NvidiaConvertor.py
#
# Tek dosya:
#   pyinstaller --noconfirm --onefile --windowed --icon "icon.ico" --add-data "icon.ico;." --collect-all customtkinter --collect-all tkinterdnd2 NvidiaConvertor.py
